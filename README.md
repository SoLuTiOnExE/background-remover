## Deploy to GitHub Pages (free)

1. Create a new GitHub repo
2. Upload **only `index.html`** to the root
3. Go to **Settings → Pages → Source → Deploy from branch → main → / (root)**
4. Your site is live at `https://yourusername.github.io/repo-name/`

That's it. One file. Zero config.

## Features
- ✂ Single image background removal with before/after preview
- 📦 Batch processing — unlimited images, one by one with live progress
- 🎨 Custom background colour (picker + hex + 8 presets)
- 🖼 Custom background image with opacity control
- ⬇ Download single PNG or all results as ZIP
- 🔒 100% private — nothing leaves your browser
- ⚡ AI runs via WebAssembly (WASM) in the browser
